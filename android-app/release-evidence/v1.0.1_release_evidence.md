## 6. Known Limitations & User Guidance

1. **Test Device In-Place Upgrade Limitation:**  
   The physical OnePlus Nord CE 2 5G runs a debug-signed build (`versionCode = 1`). Android OS will reject installing `app-release.apk` directly over it (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`). Do NOT uninstall the debug app directly without exporting an external JSON backup via in-app settings first.
2. **Local Sandbox Scope:**  
   Because cloud sync is not active, all data resides in app internal storage (`/data/data/com.kb.ledger/`). Android "Clear Storage" or app uninstall will permanently delete this data. Users must periodically use **Settings $\to$ Backup & Restore $\to$ Export Backup** to store an off-device copy in their personal storage.
3. **Off-Device Keystore Single Point of Failure:**  
   The production signing keystore (`release-keystore.jks`) currently resides only on this development workstation. An independent encrypted backup must be stored off-device before distributing to users.
